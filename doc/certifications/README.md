# Portfolio certificate library

The homepage displays all 18 supplied records: three certification/competency credentials and 15 course or professional-development certificates. Course completion and webinar participation are labeled separately from exam-based credentials.

The original AI-powered project repository webinar and Design a Web PDFs contain a national ID number. Their untouched originals are excluded from Git by the root .gitignore. The homepage links to rasterized, redacted public copies under public/ instead. Do not publish the two originals.

Certificate titles and providers were checked using PDF text and rendered pages. Dates are shown only where readable in the supplied document. The SOLIDWORKS document is a Udemy preparation-course completion certificate, not evidence of passing the CSWA exam.

For future additions, provide the PDF and record the actual title, issuer, certificate type, date where available, and any supplied verification link. Review personal details before exposing the file on the website.
